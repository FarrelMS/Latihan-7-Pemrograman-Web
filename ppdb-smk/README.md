# PPDB Online SMK Nusantara (PHP + MySQL/mysqli + Bootstrap 5)

1. Salin folder `ppdb-smk` ke `C:\xampp\htdocs\`
2. Start Apache & MySQL di XAMPP (MySQL port 3307 sesuai `config/koneksi.php`)
3. Import `database.sql` lewat phpMyAdmin (database `db_psb`)
4. Buka http://localhost/ppdb-smk/setup_admin.php SEKALI, lalu hapus file tersebut
5. Login admin: admin@ppdb.test / admin123  |  Siswa: daftar lewat halaman Registrasi
